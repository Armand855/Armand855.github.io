A website to help you learn and understand vim!!!

In this web page I plan to talk about how to access vim from your home directory, moving in vim, and basic vim commands. Lets start off with how to access vim from your home directory.

  1. First, from your home directory type " cd desktop" to get to your desktop.
  2. next, after your in your in your desktop type "cd website" to get to your website
  3. Finally, type "vim index.html" into the terminal to access vim.

Now that your in vim,you'll need to know the basic controls of vim. When you enter vim you'll be in normal mode. You can move around using arrow keys, but you can also move around using h,j,k,l. When you first load into vim you also won't be able to type because you're in normal mode. To exit normal mode click I to enter insert mode, from there you can type and edit vim.

you should learn how to use it. Heres a list of common but important vim commands they you should know to write a basic page

  • <html> is used to start and finish a web page. All the contents of the page should go inbetween the html tags.
  • <p>is used for paragraphs. You type what you want in the paragraph inbetween the tags.
  • <head> is like a mini html that only includes some content of the head like <title>.
  • <main> is where most of your writing will go. The <p> tag goes in the main tag along with many other important tags later on.

After using what you've learned about Vim you should hopefully be able to write a simple web page like this: 

 <!DOCTYPE html>
<html lang="en">
<head>
    <title>Hello World!</title>
</head>
<body>
    <p>This is my first web page.</p>
</body>
</html>

Finally, when your done editing your html page and want to save your changes you can by going back into normal mode from imput mode by hitting escape(esc). When your in normal mode you can use :q to quit out of vim without saving,:w to save while still in vim, and:wq to exit vim while saving. Enjoy making websites!!!
